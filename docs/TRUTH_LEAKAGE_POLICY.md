# Truth isolation

Hidden generation parameters are used only inside SciPy observation generation and removed from the fitting/public world state after noisy observations are created. The private supervised-session request retains generation settings to create later fresh conditions; session responses exclude that request. Neither the deterministic nor optional hosted proposal policy receives generating truth. Fitting sees observations, times, noise scale, known initial conditions and declared hypothesis assumptions. Tests inspect public JSON and fit input to check isolation. The investor's own input may name a generating scenario/mass; this is not returned to the selection policy. Fitted parameters and their uncertainty are measured inference outputs and may legitimately appear in exports.
