# Factory runtime and frontend handoff

The factory is a bounded small-carton sorting cell: one Menagerie Panda, driven
contact rollers, a lateral shuttle and two bins. MuJoCo owns motion and measured
state. React/Three.js displays that state. Opening the page creates an idle cell;
only an explicit Start or Run comparison action starts physics.

Release acceptance and executed evidence are recorded in
[FACTORY_STAGE_GATES.md](FACTORY_STAGE_GATES.md). Do not infer a passed release
gate from this API description. Previous workcell and World Labs contracts remain
documented in [SPATIAL_PIPELINE_RELEASE.md](SPATIAL_PIPELINE_RELEASE.md).

## Transport and ownership

Public frontend: `https://demo.tryvivacity.com/`. Its HTTP base is `/runtime`,
rewritten to `https://vivacity-runtime.onrender.com`; production WSS connects
directly to Render. All factory requests require `X-Workspace-Token`, a random
browser capability generated by `workspaceToken()` in `workspaceApi.ts`. Preserve
it across requests, keep it out of URLs/logs and never put provider keys in React.
This is capability ownership, not authenticated accounts or team authorization.

The complete OpenAPI files are `openapi.json` and `docs/openapi.json`; generated
TypeScript is `frontend/src/generated/api.d.ts`. Factory JSON versions begin
`vivacity.factory-…/1.0`. Request models reject unknown fields and non-finite values.
Responses can add fields. `null` means unavailable, not zero.

Errors use `{"detail":"human-readable reason"}` (schema validation can instead
return FastAPI's detail array). Handle 403/404 capability or missing records,
409 stale controller/configuration or ended run, 422 invalid input, and 429 busy
with `Retry-After: 5`. Retry bounded reads; never blindly repeat a timed-out write.
An acknowledged pause can take a controller checkpoint to become `paused`.
Poll the paused run/benchmark summary to retain its lease. A pause with no owned
summary/control requests for two minutes ends as stopped, preserving recorded
data and freeing the worker. Running jobs can finish without an open browser.

## Exact factory endpoints

All paths below start with `/v1/factory`; prepend the HTTP base above.

| Method and path | Behavior |
|---|---|
| `POST /cells` | 201; validate settings and create an idle native initial state |
| `GET /cells/{id}` | Configuration, geometry, initial state, initial frame and last run ID |
| `GET /cells/{id}/observation?source=latest` | Real synchronized RGB/depth/semantic capture; `source=initial` also supported |
| `POST /cells/{id}/runs` | 202; queue `production` or conveyor-only execution |
| `GET /runs` | Latest 30 owned saved summaries |
| `GET /runs/{id}` | Current summary, phase, frame, events and measured metrics |
| `GET /runs/{id}/record` | Full native states, plans, trace, events and metrics |
| `GET /runs/{id}/samples?after=-1&limit=400` | Indexed trace page; limit 1–1000 |
| `POST /runs/{id}/control` | Pause, resume, stop or emergency stop |
| `POST /cells/{id}/benchmarks` | 202; freeze and queue paired training/held-out trials |
| `GET /benchmarks` | Owned benchmark history |
| `GET /benchmarks/{id}` | Live trial, completed trials, comparison and failure records |
| `POST /benchmarks/{id}/control` | Pause, resume, stop or emergency stop |
| `GET /cells/{id}/export` | Strict importable configuration definition |
| `GET /benchmarks/{id}/export` | Strict importable benchmark definition |
| `GET /runs/{id}/export` | Complete measured archive; inspection-only, not importable evidence |
| `POST /imports` | 201; validate a definition and create a new idle cell; maximum 256 KiB |
| `GET /reports/run/{id}?format=pdf` | Saved-data PDF; `format=zip` includes CSV/JSON and definitions |
| `GET /reports/benchmark/{id}?format=pdf` | Comparison PDF; ZIP contains every recorded trial |
| `GET /projects`, `POST /projects` | List/create owned project notebooks |
| `GET /projects/{id}` | Versions, attribution and result attachments |
| `POST /projects/{id}/versions` | Append immutable configuration version with revision check |
| `POST /projects/{id}/attachments` | Attach a terminal run/benchmark with revision check |

Changing conditions or Reset creates another cell, preserving prior results.
Results shown for an older cell must stay labeled as previous results. A new
controller/model rejects stale execution; applying conditions creates a compatible
initial state. Reset must never start a run.

### Request examples

Create a quick, supported one-carton cell:

```json
{"name":"Contact sorting baseline","seed":19,"carton_count":1,
 "carton_mass_kg":0.06,"carton_friction":0.8,"carton_half_size_m":0.025,
 "carton_start_x_m":0.5,"carton_start_y_m":-0.4,
 "conveyor_speed_m_s":0.09,"arrival_interval_s":18,"realtime_speed":8,
 "sort_threshold_kg":0.07,"gripper_force_scale":1}
```

Use the returned `id` in `POST /cells/{id}/runs`:

```json
{"mode":"production","creator_label":"Demo engineer"}
```

The run response has `id`, `cell_id`, `status`, `phase`, `frame`, `events`,
`metrics`, `error` and provenance. Read `/runs/{id}` until a terminal status:
`completed`, `failed`, `stopped`, `emergency_stopped` or `interrupted`.
`queued`, `running` and `paused` remain active. Never interpret HTTP 202 as success.
Saved telemetry is paged in SQLite with at most 100 pending samples in worker
memory. Full JSON downloads stream these pages. Clients can use ordinary JSON
decoding for a completed download; no custom stream format is required.

Pause/resume bodies are `{"action":"pause"}` / `{"action":"resume"}`.
Stop ends a run. Emergency stop records a simulation interruption; it is not a
certified hardware safety function. A restarted process marks active jobs interrupted.
After an unexpected process loss, already flushed trace pages remain inspectable;
up to 99 pending samples can be lost. An interrupted job does not claim a final
native state or resume from an unrecorded state.

Six-trial physical comparison, with an intentionally weak candidate condition:

```json
{"name":"Contact robustness","repeats":2,"held_out_repeats":1,
 "changes":{"carton_mass_kg":0.15,"carton_friction":0.05,"gripper_force_scale":0.005}}
```

Failures are determined by executed contacts/tracking, not this example. Selection
uses completed training success rate, then mean successful duration; all-fail
returns no selection. Held-out results never change selection. Current jobs have
6–10 serial independent trials, not 5,000 parallel factory runs.

Project example: `POST /projects` with
`{"name":"Sorting study","team_label":"Research","creator_label":"Engineer"}`.
Save a version using `{"cell_id":"<returned cell id>","expected_revision":1,
"creator_label":"Engineer","note":"Baseline"}`. Use the latest returned revision
when attaching `{"kind":"run","record_id":"<run id>","expected_revision":2,
"added_by_label":"Engineer"}`. Report `project_id` optionally adds that notebook's
declared attribution. Labels are not verified identities.

### Replay, transforms and measurements

Sample pages have `schema_version`, `run_id`, `frames`, `next_index`,
`total_samples`, `status`. Start `after=-1`, append returned frames, then request
`after=next_index`. Do not synthesize extra frames or count rendered frames as
simulation iterations. Native steps are 0.002 s; ordinary saved samples are about
20 Hz with additional exact event-time samples.

Every frame carries `time`, `qpos`, `qvel`, `ctrl`, `body_transforms`, `cartons`,
`end_effector`, conveyor measurements and `measurements`. Coordinates are
right-handed Z-up, metres. Native quaternions are `[w,x,y,z]`; Three requires
`[x,y,z,w]`. Named body transforms are world poses. Use the shared
`vivacity/factory_layout.json`, `FactoryView.tsx` and existing `RobotView.tsx` mesh
hierarchy. Do not compute another physics solution in the browser.

`collision_geometry` describes named primitive shapes, world position, wxyz
orientation, native sizes and `moving_with_shuttle`. Box sizes are half-extents;
cylinder sizes are radius and half-length. Detailed visual assets are separate
from collision geometry and must not be presented as reconstructed real hardware.

`measurements` contains native joint torque/velocity/acceleration, contact forces,
object COM/mass/inertia/friction, mechanical power and work. See
[FACTORY_MEASUREMENTS.md](FACTORY_MEASUREMENTS.md) for units, equations and
force-time versus integrated-pose-time semantics. Graphs, selected events and 3D
replay must share the same saved-sample cursor. Mechanical work is integrated
every physics step. Electrical energy remains `null`.

Camera response contains `camera` and captured `ground_truth`. `camera` includes
PNG `image_data_url`, width/height, focal length, world camera pose and detections
with bounding boxes, visible pixels and estimated centre. Semantic IDs are
simulator annotations, not a trained detector. Confidence is `null`. Occlusion and
outside-view are explicit. Centre reconstruction assumes an upright configured box.

Factory execution currently uses HTTP polling, not a factory WebSocket. Existing
workcell WSS remains `/v1/experiments/{id}/events` and `/live`, with subprotocols
`vivacity.live` and `vivacity.token.<session capability>`. Event envelopes and live
frames are the existing `EventResponse`/`LiveState` schemas in OpenAPI. Do not send
the workspace capability as a substitute for an experiment's session capability.

### Interchange and reports

Import the entire exported definition unchanged. It includes schema, units,
configuration, seed, initial state, definition checksum and software provenance.
Compatibility checks cover MuJoCo, NumPy, SciPy, Python major/minor, controller,
assets/layout and reconstructed native initial state. Cross-platform bitwise
identity is not promised. Old measurements remain readable even when their
definitions cannot run under a newer controller. Imported results never become
verified executions.

PDFs use stored measurements and vector charts; ZIP adds every trial's CSV/JSON.
Reports require terminal records and no active factory job. The benchmark PDF
analyzes its first recorded trial plus the complete comparison; ZIP includes all
recorded trials. Missing provenance stays unavailable. PDFs have searchable text;
fully tagged accessible PDF output remains unimplemented.

## Frontend files to extend

- `frontend/src/FactoryWorkspace.tsx`: explicit start/conditions, controls and errors.
- `FactoryView.tsx`: detailed factory composition and measured transforms.
- `FactoryAnalysis.tsx`, `factoryAnalysisData.ts`: synchronized graphs and exports.
- `FactoryWorkspace.tsx`, `FactoryObservation.tsx`: native measurements/camera.
- `FactoryBenchmark.tsx`, `FactoryProjects.tsx`, `FactoryExchange.tsx`: comparisons, notebooks and interchange.
- `factoryApi.ts`, `apiTransport.ts`, `workspaceApi.ts`: typed requests, routing and capabilities.
- `factory.css`, `engineering.css`: factory/shared styling and responsive/keyboard states.

`vivacity/factory_layout.json` is the layout source. Vercel uploads only
`frontend/`, so `generate:factory` copies it to `frontend/src/generated/`.
The frontend test suite requires exact byte equality; commit both files when
changing layout. Do not import files outside the frontend deployment root.

Preserve the stage-tested layout. Add a feature only after its native/API test and
real browser journey pass. Do not replace the factory with a video, fake traces,
scripted carton poses or an unverified perception claim.

## Deployment limits

The existing Render Free service has 512 MiB, sleeps after inactivity and uses
ephemeral SQLite/files. No uptime pinger makes that a paid always-on durable
service. Export important results. Persistent storage, authenticated team sharing,
multi-instance workers and production uptime require a separate deployment change.

The factory is a finite 1–3 carton batch with one tested Panda controller and
bounded inputs, not arbitrary carton geometry/any robot/any workspace. Serial
factory comparisons share the execution lane with legacy workcells. Existing
workcell trials support their separately bounded parallel worker contract. No
hardware reliability, learned vision, general autonomous planning, bimanual cloth
controller or World Labs Atlas functionality is claimed.
