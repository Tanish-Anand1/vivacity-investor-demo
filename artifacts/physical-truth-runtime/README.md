# Executed research evidence

These are local research results, **not a Physical Truth production release**.
`verification-summary.json` is generated by `scripts.summarize_contact_verification`
after the complete native G1 acceptance run and focused tests finish. It checks
that the recorded source hashes match the implementation. Full results and the
real HTTP journey are gzip-compressed to preserve measurements without bloating
the repository. Decompress them with Python's standard `gzip` module.

`verified-native-contact-sheet.png` renders the actual HTTP replay against the
same compiled-model hash. From left to right: approach, grip, lift, hold; then
transfer, lower, release, settle. These are replay views, not live screenshots or
evidence of camera perception. The per-frame measurements and times are retained
in `verified-native-images.json`.

Failed whole-body and alternate-solver trials are retained deliberately. Neither
is a successful controller release. XML reports identify the exact executed test
cases; overlapping suites must not be added together as independent test counts.

SQLite files, owner capabilities, scratch renders, build logs, and temporary
uncompressed reports are not published. No hardware test, GPU training, paid
hosting purchase, production soak, or cinematic update is represented here.

`constrained-cutoff-failed-acceptance.json.gz` retains the failed 19/20 nominal run of the first native-actuator wrench controller. Its wall-clock solver cutoff returned MaxTime under host contention. Revised source has a different hash and requires a separate acceptance report; this failed sample is never merged into it.
